# Sandbox Provider 与 OpenSandbox 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 在Harness落地可替换Sandbox装配、完整远端工作区和首个OpenSandbox可选后端，并补齐技术与使用文档。
**Architecture:** 根sandbox包复用GoAgent env接口并管理会话所有权；preset按宿主Registry装配；供应商SDK位于独立子模块。命令和文件绑定同一后端，不新建Agent循环。
**Tech Stack:** Go1.25、GoAgent v0.32.2、OpenSandbox release-1.2.0、Linux python3文件辅助程序、现有Docker验证环境。
**Spec:** docs/design/SANDBOX.md。

## Global Constraints

- 不改GoAgent主库；原local/docker用法兼容；根模块不直接依赖OpenSandbox SDK。
- Go命令env -u GOROOT GOTOOLCHAIN=go1.25.0；仅本地提交，不推送/发布/合并。
- 先RED再GREEN；无法确认远端停止不得伪造已停止；任何超时仍保留清理责任。
- 首期Docker服务后端、python3镜像、network=true；不支持的能力在创建前拒绝。
- 默认输出1MiB、RPC8MiB、单文件4MiB、遍历10000项、工作区/workspace/goagent、TTL10分钟、清理5秒、操作30秒。

## Review Focus

1. Create/Connect取消后迟到返回的资源和关闭重试，不得泄漏或误删borrowed实例（Task1/3）。
2. 编码工具的Resolve/写入链接竞态、条件写协调范围、Walk跳过语义（Task4）。
3. 参数边界、已知命令非零退出与传输未知结果、输出溢出必须停止实际命令（Task3）。
4. 父子网络/隔离扩权在创建前拒绝，Manifest不把新空环境当恢复（Task2）。
5. 镜像/服务/SDK版本或python3缺失，须在装配时失败且回收（Task3/5）。
